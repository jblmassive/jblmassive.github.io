# Jungle Book Legion website

GitHub Pages serves the frontend from the main branch. Jekyll builds the shared layout in `_layouts/jbl.html` and the navigation, footer and homepage content in `_includes/`. Edit `_includes/homepage.html` to update both `/` and `/home.html`.

The primary pages are `/`, `/events.html`, `/music.html` and `/production.html`. The legacy `/equipmenthire.html` URL points to the production catalogue. The legacy `/artists.html` and `/aboutcontact.html` URLs redirect to Music and Contact. The general contact form is at `/contact.html`.

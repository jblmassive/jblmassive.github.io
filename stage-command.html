Multicam

Bring in the camera angles from a set and sync them to a shared audio track. Stage Command lets you cut between angles, build highlights and set recaps, then send the edits to Social Studio for branded exports.

Built for show day

I’m building Stage Command to keep the running order, artist requirements and stage handovers together. When a set runs long, I want to see what that means for the next act and how much time we have before curfew.

What’s working today

Build the running order

Schedule artists and changeovers, assign stages and risers, and keep equipment notes and riders with each act.

Track what happens live

Log actual starts and finishes, check setup readiness, and keep track of requests and issues during the show.

See the impact of an overrun

Preview changes to later slots while respecting fixed starts, minimum set lengths and the show curfew.

Social Studio

Take highlights from a live set or bring in an edited recap. Social Studio lets you preview clips, adjust audio levels, add your logo and export in several sizes for social media, ready to hand off to the team for posting.
